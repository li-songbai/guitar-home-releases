# 🎸 乐手音律站（乐手之家联名 APP）安装包发布仓

本仓库仅用于公开托管 **乐手音律站（Guitar Home）** 的官方签名 Android 安装包（APK）与版本更新清单（[`latest.json`](./latest.json)），不包含应用源码。

## 📥 下载与安装
- 前往右侧 **[Releases](https://github.com/li-songbai/guitar-home-releases/releases/latest)** 下载最新版本的 `arm64-v8a` 安装包。
- 已安装用户可在 App 顶部点击更新图标直接检测、校验并一键更新至最新版本。

## 📋 系统要求
- Android 8.0+（`API 26+`）
- `arm64-v8a` 架构真机
